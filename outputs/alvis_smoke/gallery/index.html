ASF Corruption Study — Clean vs Noisy Sensor Data

Per-sensor corruption sweep on the K-Radar 6-frame sample (sequences 1 & 2, the 3 densest frames each). Each condition applies exactly one effect to exactly one modality; every other sensor is clean. Seed: 42 · conf_thr: 0.3

These are the actual tensors handed to the model, dumped at inference time — not re-simulated afterwards. Every CLEAN / CORRUPTED pair is the same frame before and after injection. Point clouds are rendered in BEV; the ROI is x 0–72 m, y ±16 m.

Reading loss_partial and _zeros: these zero points in place rather than deleting them, so the affected points collapse to the origin. They use the zero-out-aware renderer (magenta marker + origin inset + counts), matching the existing noise visual inspection gallery.

Detection counts are from corruption_summary.csv; see outputs/alvis_smoke/RESULTS.md for the full analysis and caveats.
