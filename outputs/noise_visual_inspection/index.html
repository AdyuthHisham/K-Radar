Noise Injection — Visual Inspection (v3, severity levels)

12-effect taxonomy (Rev 2) applied to 3 real K-Radar frames, at low/medium/high severity where a severity axis exists. Seed: 42

v3 adds severity levels to v2. Each severity-capable effect now shows three renders side-by-side (low | medium | high) using values reused directly from noise-injection-param-sweep-report.md's tested points. loss_complete has no severity axis (always full clear regardless of params, confirmed in the param sweep) and is shown as a single reference image per modality. radar/lidar loss_partial still use the zero-out-aware render_bev_zeroout() (magenta marker + zoomed origin inset + counts) at every severity. See noise-visual-inspection-severity-levels-report.md.
